# Publish with GitHub Pages

1. Open Settings > Pages.
2. Select Deploy from a branch, main, / (root), then Save.
3. Check the Pages deployment completes before changing DNS.
4. To use niraminniefield.com, verify the domain in GitHub account settings, then add it under the repository Pages custom domain settings before updating GoDaddy DNS.
5. Enable Enforce HTTPS once the certificate is ready.

The site is static. Edit index.html for content and styles; images are in assets/. No build or dependency installation is required.

When publishing from main, future commits to main will update the public website.
